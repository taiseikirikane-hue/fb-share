# FRU+TAS フレーバービンゴ（モック）

tob（シーシャフレーバー B2B EC）内で店舗担当者向けに、
FRU+TAS（フルタス）全 62 種フレーバーの「コンプ意欲」を刺激するビンゴ UI。

注文したフレーバーがマスに反映され、行 / 列 / 斜めラインでクーポンが発火、
全 62 種コンプで大特典。

---

## フレーバー・特典の書き換え手順

このモックは 2 つの JS ファイルだけで内容が変わる。コードは触らない。

### 1. フレーバーを差し替える

`flavors.js` を任意のテキストエディタ（メモ帳 / VS Code など）で開く。

```js
const FLAVORS = [
  { id: 1,  name: "Blueberry Mint",  nameJa: "ブルーベリーミント",  color: "#4E7BE0", category: "fruit" },
  { id: 2,  name: "Peach Ice",       nameJa: "ピーチアイス",        color: "#F4A6B8", category: "fruit" },
  // ... 全 62 種
];
```

書き換えるのは以下の 4 項目：

| 項目 | 内容 |
|---|---|
| `name` | フレーバー名（英字表記、盤面に表示） |
| `nameJa` | フレーバー名（日本語表記、任意。省略可） |
| `color` | マスの色ドット HEX カラー（例: `"#F4A6B8"`） |
| `category` | カテゴリ（`fruit` / `mint` / `dessert` / `spice` / `floral` / `drink`）|

- `id` は**変更しない**（一意ID、盤面の順序制御に使用）
- 配列の**要素数は 62 のまま**（増減させると盤面レイアウトが崩れる）
- HEX カラーは `#` から始まる 6 桁

### 2. 特典（クーポン）を差し替える

`rewards.js` を開く。

```js
const REWARDS = {
  oneLine:    { linesRequired: 1, discountYen: 500,   label: "¥500 OFF クーポン獲得" },
  threeLines: { linesRequired: 3, discountYen: 2000,  label: "¥2,000 OFF クーポン獲得" },
  complete:   { allCells: true,   discountYen: 10000, label: "全 62 種コンプリート ¥10,000 OFF" },
};
```

- `discountYen` : 割引額（円、半角数字）
- `label` : モーダル・進捗バッジに表示する文言

### 3. 保存する

保存後、`index.html` を再読み込みするだけで反映される。

## ローカル動作確認

`index.html` をダブルクリックしてブラウザで開けば動く。サーバー起動は不要。

- マスにマウスホバー（PC） / タップ（モバイル）で「注文する」ボタン表示
- 「注文する」を押すとマスが埋まる → ラインが揃うとクーポン発火
- 「デモ埋め」ボタンで段階的に自動スタンプ（1 ライン → 3 ライン → コンプ）
- 「リセット」で初期状態に戻る

## 盤面ルール（参考）

- 8 × 8 = **64 マス** 構成、中央 2 マスは特殊マス（FREE / FRU+TAS ロゴ）
- 残り **62 マス** がフレーバー
- ライン成立判定：**行 8 本 + 列 8 本 + 斜め 2 本 = 最大 18 本**
- 特殊マス（FREE / ロゴ）は「常に埋まっている」扱い
- ライン達成本数：
  - **1 ライン** → `oneLine` リワード
  - **3 ライン以上** → `threeLines` リワード
  - **全 62 マス埋め** → `complete` リワード（コンプリート大演出）

- FRU+TAS ブランドカラー（ディープパープル + イエロー差し色）をベースに、
  ビンゴらしいマルチカラーを乗せる
- ブランド表記は「**FRU+TAS**（フルタス）」で固定。綴りを変えない
- `tob` は小文字表記で統一
- 効果音なし（EC 店舗で使う想定）
